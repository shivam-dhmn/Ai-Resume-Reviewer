# AI Resume Reviewer

## Overview

AI Resume Reviewer is a SaaS application that helps job seekers improve their resumes using AI.

Users can upload a PDF resume and receive:
- ATS compatibility analysis
- Resume score
- Strengths and weaknesses
- Missing keywords
- Grammar suggestions
- Actionable improvements

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- MongoDB
- Prisma
- OpenRouter (Free AI Models)
- Vercel
